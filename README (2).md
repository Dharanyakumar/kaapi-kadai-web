# Kaapi Kadai: Responsive Website for a Filter Coffee House

A sample website built during the 15-day inplant training at Ensemble Nexgen, Erode (June to July 2026).

## Features
- Responsive layout for desktop and mobile (Flexbox, Grid and media queries)
- Menu table with category filter (All, Coffee, Tea, Snacks)
- Order tray: add items, change quantities, see the total
- Pick-up request form with validation for name, mobile number, email and pick-up time

## Technologies used
HTML5, CSS3, JavaScript, Visual Studio Code, Google Chrome, Git and GitHub

## How to run
Download `index.html` and open it in any web browser. No installation is needed.
